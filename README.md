# StudyFlow: Smart Tasks

Create a modern and attractive web application called "StudyFlow – Smart Student Task Manager". The app should help students manage their daily study tasks. Include a dashboard with Total Tasks, Completed Tasks, and Pending Tasks. Add a form to create tasks with Task Name, Subject, Priority (High, Medium, Low), and Due Date. Display all tasks in beautiful cards. Allow users to mark tasks as completed and delete tasks. Include a study motivation quote section and a clean, colorful, student-friendly UI. Make the application fully responsive and professional.
